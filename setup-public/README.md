# UChicago Python & AI Workshop — setup check

Before the workshop, please run the setup notebook once (≈10 minutes). It confirms you can run Python in the browser via Google Colab and load the workshop data — no installation needed.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/limorigu/uchicago-workshop-setup/blob/main/notebooks/00_setup_check.ipynb)

1. Click the badge above (sign in with a Google account — use a personal Gmail if your university account says Colab is disabled).
2. Run each cell with **Shift+Enter**.
3. If the last cell prints **"You're ready"**, you're done. If not, screenshot the error and email the instructor.

The full workshop materials will be shared closer to the day.
